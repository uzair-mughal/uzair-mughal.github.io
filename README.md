# Uzair Ahmed Mughal

Personal website: **https://uzair-mughal.github.io/**

A minimal, responsive website made with plain HTML and CSS. No build step, dependencies, JavaScript, or tracking.

## Edit

- `index.html`: biography, experience, education, selected work, and links.
- `styles.css`: desktop, mobile, keyboard focus, and print styles.
- `favicon.svg`: initials icon.
- `portrait.svg`: optimized profile photo.

Edit the content and commit to `master`. GitHub Pages automatically publishes the updated site.

## Run locally

Open `index.html` in a browser, or serve this directory with `python -m http.server 4173` and visit http://localhost:4173/.

## Hosting

GitHub Pages publishes the `master` branch from `/ (root)`. Hosting and the `github.io` address are free.
